# Política de segurança

Este repositório é o espelho só-leitura de uma pasta do monorepo do
**TWS Laravel Starter Kit**. As vulnerabilidades são tratadas lá.

- **Não abra issue pública** para vulnerabilidades.
- Reporte pelo canal privado do GitHub, no monorepo:
  <https://github.com/kelvindk9w/tws-laravel-starter-kit/security/advisories/new>.
- A política completa (prazos, versões suportadas, o que já está coberto) é
  a do monorepo:
  <https://github.com/kelvindk9w/tws-laravel-starter-kit/blob/desenvolvimento/SECURITY.md>.

# Security policy (English)

This repository is a read-only mirror of a folder of the **TWS Laravel
Starter Kit** monorepo, where vulnerabilities are handled. Please **do not
open public issues**: report privately at
<https://github.com/kelvindk9w/tws-laravel-starter-kit/security/advisories/new>.
Full policy: <https://github.com/kelvindk9w/tws-laravel-starter-kit/blob/desenvolvimento/SECURITY.md>.
